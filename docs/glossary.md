# 📖 Glossary

| Term | Meaning |
|---|---|
| Classifier | Model that assigns an input to one of several labels |
| TF-IDF | Term Frequency-Inverse Document Frequency feature representation |
| Label encoder | Mapping from category strings to model class identifiers |
| Data leakage | Information from evaluation data entering model training/preprocessing |
| Pickle | Python serialization format that is unsafe for untrusted input |
| OAuth | Delegated authorization protocol used in the Google sign-in flow |
| Provider | External job-search service called by the app |
| Model card | Structured description of model purpose, limitations, and evaluation |
| Provenance | Documented origin and history of a dataset or artifact |
| Abstention | Model behavior that declines to provide a prediction when confidence/evidence is insufficient |
| Synthetic data | Artificial test examples that do not describe real people |
